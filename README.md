# Grooooaaaark Zig-commit-emojis

## How do I install these formulae?

`brew install grooooaaaark/zig-commit-emojis/<formula>`

Or `brew tap grooooaaaark/zig-commit-emojis` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "grooooaaaark/zig-commit-emojis"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
